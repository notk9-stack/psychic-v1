# Iftekhar Hosting Server

A complete web hosting dashboard with file upload, ZIP extraction, and script management.

## Features

- 📁 Drag & drop file upload
- 🗜️ Automatic ZIP extraction
- 🔵 Start, 🔴 Stop, 🟢 Restart script controls
- 📊 Real-time stdout/stderr console
- 💾 Local file database
- 🎨 Modern responsive UI

## Deployment on Railway

1. Push this repository to GitHub
2. Go to [Railway.app](https://railway.app)
3. Click "New Project" → "Deploy from GitHub repo"
4. Select your repository
5. Railway auto-deploys!
